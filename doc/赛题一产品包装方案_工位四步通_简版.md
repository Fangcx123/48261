# 赛题一产品包装方案（简版）

方案讨论稿：以下“上电播报一次、按键重播、切图短音效”为拟实现交互，需要修改现有 RTL 并验证，不代表当前固件已具备。

## 一、产品定位

“工位四步通”是一款面向高校电子实训室的离线操作引导终端。它把教师审核后的焊接规程制作成四张图文卡，安装在工位旁：

1. **准备**：工具、工件和安全注意事项；
2. **操作**：动作顺序、位置和关键要点；
3. **对照**：合格与常见不良外观；
4. **收尾**：检查项目、工具归位和结果确认。

教师课前用自动轮播讲解，学生操作时停止轮播并手动查阅，完成后按第四张卡自检。设备由 FPGA、TF 卡、SDRAM、HDMI 显示器和两个按键组成，固化后可脱离电脑运行。

## 二、一次完整使用故事

实训开始前，教师把本次任务的四张 BMP 图片和可选语音文件复制到 TF 卡。设备上电后扫描并预载四张图片，显示第一张有效卡，并自动播放一次通用指导语音。语音结束后保持安静，学生需要时可通过按键重播。

教师开启自动轮播，依次介绍准备、操作、对照和收尾要求。学生开始焊接后按 KEY2 停止轮播，用 KEY1 前后翻页，停留在当前需要参考的页面；切换成功后响一声短提示音。如果不确定目标内容，可长按 KEY2 进入四图预览快速定位。

焊接完成后，学生查看第三张卡对照外观，再查看第四张卡完成检查和工具归位。整个过程不需要打开电脑，也不需要反复寻找纸质资料。

## 四、音频行为说明

**目标交互：开机讲一次，需要再听，翻页有反馈，其余时间安静。**

- **上电播报**：图片预载及音频准备完成后，自动播放一遍 AUDIO.WAV，最后一个样本输出完成后停止，不循环。内容为终端用法和通用注意事项，不逐页讲解。
- **按键重播**：暂定在现有菜单 B/C/V/P 后增加 R（Replay）动作项。全屏长按 KEY2 进入预览，再长按进入菜单；短按 KEY2 选到 R，短按 KEY1 从头播放一次指导语音，并返回原全屏页，保持手动定页。R 是动作项，不是数值参数；不增加实体按键。
- **避免重复触发**：语音播放中再次请求重播时，不重启、不排队，显示播放状态。播完后才能再次重播。
- **切图音效**：未播放语音时，每次实际切换到另一张图片，在转场结束后播放约 100 ms 的短提示音，然后恢复静音；手动翻页、预览选图和自动轮播均适用。移动预览焦点、修改参数或切图失败不发声。
- **语音优先**：播报期间允许翻页，但不叠加或补播切图音效。保留手动转场音量包络，不重置语音位置；通用语音与当前页没有一一对应关系。
- **缺失或错误**：没有有效 AUDIO.WAV 时跳过开机语音，重播时提示“语音不可用”，图片查阅和短提示音仍可用，不播放持续背景旋律。
- **音量与波形**：音量统一控制语音和音效，静音时两者均不发声。波形显示最终输出 PCM：语音或音效播放时有变化，安静时回到中线。

**可实现性与改动范围：** 已有 WAV 解码、音频 FIFO、DDS 和两键菜单可复用。需将 WAV 循环改为单次播放，增加重播请求及跨域握手，在文件读取结束后继续输出 FIFO 剩余样本，排空后才标记播放结束；重播前协调读卡、解码器和 FIFO 状态，避免残留样本。另增加菜单 R、播放状态及语音/音效/静音选择，关闭持续琶音。无需新增音频文件或外设，新增资源与时序需构建验证。

重点验收：上电只播一次、末尾不截断、重播从头开始、连续按键不重复排队、语音与音效不重叠、无 WAV 时仍可切图提示，以及静音和复位行为。

## 五、建议的现场演示顺序

1. **上电**：展示首张卡，听取一次指导语音，确认播完后安静；
2. **自动轮播**：演示课前讲解模式；
3. **手动查阅**：停止轮播，短按/长按 KEY1 翻页；
4. **四图预览**：长按 KEY2，移动焦点并确认页面；
5. **参数设置**：调整亮度、对比度、音量和轮播时间；
6. **音频功能**：选择 R 重播指导语音，展示播放状态、波形和峰值；播完再翻页，听到短音效后恢复安静；
7. **故障处理**：演示缺图或非法 WAV 的提示与回退；
8. **断电重启**：说明固化后可以独立运行。

## 六、答辩话术

> “工位四步通”把一项实训任务组织成准备、操作、对照和收尾四个环节。我们设计了“开机讲一次、需要再听、翻页有反馈”的声音交互：首次使用时听取操作说明，实训过程中按需查阅，忘记用法时按键重播，平时保持安静。教师用自动轮播进行课前讲解，学生用两个按键找到所需页面，最后对照图片并完成收尾检查。FPGA 的文件读取、图像缓存、语音播放和音效合成，共同服务于这条完整的实训流程。

## 七、表达边界

本方案最多缓存四张图片，WAV 为单份通用语音，不支持逐页独立语音；波形是时域波形，不是 FFT 频谱；参数掉电后恢复默认。现有固件仍为 WAV 循环及无 WAV 时的持续琶音，本次提出的单次播报、菜单重播和独立切图短音效均待开发。真实板卡的冷启动、听音和长时间运行，应以最终实测记录作为验收依据。
