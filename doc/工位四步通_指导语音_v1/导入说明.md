# 工位四步通：指导语音试听版

生成日期：2026-10-25。

## 导入TF卡

1. 关闭开发板电源，取出TF卡。
2. 备份TF卡根目录原有的 AUDIO.WAV。
3. 只将本目录的 AUDIO.WAV 复制到FAT32卡根目录，保持文件名不变；四张PIC图片继续保留。
4. 安全弹出卡，插回开发板后上电。

## 文件参数

- 内容：讲稿.txt中的终端操作说明，按键二、按键四均对应开发板丝印KEY2、KEY4。
- 声音：Microsoft Huihui Desktop，本地中文合成女声。
- 格式：RIFF/WAVE、PCM format=1、48000 Hz、16位、单声道；解码器将单声道复制到左右声道。
- 时长：48.594秒；文件大小：4,665,116字节。
- 峰值：约-3 dBFS，无满幅削波样本；实际听感受工程V音量和显示器音量影响。
- 已检查WAV头、数据长度、样本数、文件大小和峰值；未进行实板听音验收。

## RTL 方案一行为

对应 RTL 候选工程 `src/td_project_workstation_v10/HDMI1.4b_Transmitter_v1.0.al`：首张有效图片显示后延时约 2 秒播放一次；播完后静音。菜单 R 可从头重播，并显示跟随 PCM 样本位置的中文字幕。板上丝印 KEY2、KEY4 对应逻辑 RTL key1、key2；板上 KEY1 是复位。

上述行为已经完成 RTL 和仿真验证，但尚未完成最终 routed 时序确认、板上烧录和实板听音。字幕时间点根据讲稿停顿估计，实听后可能需要校准。

讲稿.txt、格式检查.json和语音源_本地女声.wav供电脑端维护，无需复制到TF卡。
