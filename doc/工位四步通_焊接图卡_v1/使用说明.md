# 工位四步通：焊接入门四图

本内容包对应“准备、操作、对照、收尾”四张步骤卡。采用中文排版和程序绘制的教学示意图，不使用 AI 生成照片。版本 V1.0，日期 2026-10-24。

## 文件与用途

| 文件 | 内容 |
|---|---|
| TF卡文件/PIC1.BMP | 准备：断电固定、工具准备、排烟 |
| TF卡文件/PIC2.BMP | 操作：同时加热、送锡、先撤焊锡、再移烙铁 |
| TF卡文件/PIC3.BMP | 对照：参考连接形态、连锡风险、焊料不足 |
| TF卡文件/PIC4.BMP | 收尾：焊点复核、装配核对、烙铁归架、工位整理 |

“工位四步通_TF四图.zip”内仅含这四个 BMP，直接解压即可使用。PNG 为电脑预览，generate_cards.py 为可编辑的生成源文件；不必把这些文件复制到 TF 卡。

## 已检查的格式

- 640×480 像素，4:3；24 位 RGB，无透明通道，无调色板。
- Windows BMP，BITMAPINFOHEADER=40 字节，compression=0（BI_RGB，无压缩）。
- 正高度 480，即 bottom-up；像素 BGR 顺序、每行 1920 字节，满足四字节对齐。
- 像素起点为 54 字节，每个文件为 921,654 字节，小于工程 16 MiB 上限。
- 已重新解码比对全部像素，并抽查原始 bottom-up/BGR 字节顺序；文件参数和 SHA-256 见“格式检查.json”。

## 显示布局

正文安排在 y=64～359。y=0～63 留给原有页号、模式、计时和参数行；y=360～479 留给波形、峰值和字幕。深色留白是界面叠加背景，并非缺失图像。图片没有绘制假的音频波形或播放状态。

“缩略效果参考.png”仅模拟低分辨率 RGB332 观感，不是 RTL 逐像素输出或实板截图；小图用于定位，大图用于阅读。

## 使用

1. 断开开发板电源，在电脑上保留 TF 卡现有 PIC1.BMP～PIC4.BMP 的备份。
2. 将“TF卡文件”中的四个 BMP 普通复制到 FAT32 卡根目录，保持文件名不变。
3. 安全弹出卡，插回开发板并上电，等待预载。
4. 逐张全屏查看中文、示意图和边缘，再检查四图预览及现有 OSD 的实际叠加位置。

本次仅生成本地素材，没有写入 TF 卡、修改 RTL 或升级固件。图卡适用于现有显示功能；上电单次语音、按键重播等目标音频交互仍需另外实现。

本包是方案演示素材，示意图不替代实物检查标准；正式用于教学前，应由任课教师确认工艺与措辞。未把普通无铅焊点的哑光外观直接判为不良，也未规定统一温度或加热秒数。
